Judul Permintaan
Sensor PLC Conveyor Rusak
Deskripsi Lengkap
Sensor proximity PLC pada jalur konveyor utama stasiun 3 perakitan terdeteksi intermittent error dan sering berhenti mendadak sejak pagi ini pukul 08:00 WIB. Akibatnya jalur perakitan mengalami hambatan laju produksi. Mohon bantuan PIC teknisi untuk segera melakukan pemeriksaan modul sensor, wiring junction box, dan kalibrasi ulang controller agar jalur produksi dapat beroperasi normal kembali.
